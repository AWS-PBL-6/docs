## 1. 검증 범위와 방법

- 대상: 안벽 볼라드 부착 접촉식 AE 센서 시나리오로 변환된 이벤트 단위
  데이터셋 (관측 피처 17개 + 진실값 3개 + 라벨)
- 방법: ① 구조 검사 ② 물리 정합성 검사(변환 체인이 의도한 물리를 만드는지)
  ③ 구성 통계 검사 ④ 모델 기반 검증(XGBoost, 세션 단위 GroupKFold 5-fold)
- 환경: vendored pandas 3.0 / scikit-learn 1.9 / xgboost 3.3

## 3. 물리 정합성 검증

변환 체인(진폭 사상 → 거리 감쇠 → 부동 검출 임계 → 교란 주입)이 의도한
물리적 질서를 실제로 만들어내는지 확인했다.

**3.1 검출 계층이 신호 에너지 순서를 따르는가 — 통과**

| 신호군 (소스레벨) | 로프 이벤트 생존율 |
|---|---|
| High amplitude (85 dB_AE) | 99.9% |
| Medium amplitude (62 dB_AE) | 85.5% |
| Low amplitude (54 dB_AE) | 43.4% |
| Low-to-high freq (46 dB_AE, HPF 잔존) | 13.2% |

강한 신호일수록 잘 검출되고, 저진폭 신호는 거리·기상에 따라 소실된다
(전체 로프 이벤트 미탐 41.8%). 옥외 AE 계측의 실제 거동과 방향이 일치한다.

**3.2 클래스별 관측 구성이 현실 서사와 일치하는가 — 통과**

| 클래스 | ROPE | CRANE | RAIN | WIND | 로프 이벤트 생존율 |
|---|---|---|---|---|---|
| 안전 | 2,339 (17%) | 4,970 | 4,531 | 2,128 | 35.8% |
| 주의 | 6,115 (55%) | 2,692 | 1,307 | 975 | 46.5% |
| 위험 | 8,999 (86%) | 551 | 405 | 501 | 87.3% |

안전 상태의 관측은 대부분 환경음(83%)이다 — 논문에서 50% MBL 미만의 로프는
거의 침묵하므로, "조용한 홋줄의 로그 = 배경 소음"이라는 구성은 원본 30k보다
오히려 실제에 가깝다. 위험으로 갈수록 로프 기원 이벤트가 지배한다.

**3.3 진폭·노이즈 스케일 — 통과**

- 로프 이벤트 37.6~101.4 dB_AE (고진폭군이 와이어로프 파단 실측대 80~100 dB_AE 포함)
- 교란원은 42.5~84.5 dB_AE로 로프 신호와 **중첩** — 의도된 난이도
- 노이즈 플로어 28.7~63.3 dB_AE, SNR 6.0~65.9 dB (부동 임계 +6 dB 규약과 일관)

**3.4 라벨 누수 차단 — 통과**

생성 진실값(`Truth_Source`, `Truth_Distance_m`, `Truth_Load_MBL_Ratio`)은
접두사로 분리되어 학습 피처 후보에서 제외된다. 관측 피처만으로는 라벨을
결정하는 규칙이 존재하지 않는다(§4의 단일 이벤트 성능 69%가 그 증거).

## 4. 모델 기반 검증 (XGBoost · GroupKFold 5 by Session)

| 설정 | 정확도 | macro-F1 | 위험 재현율 / 정밀도 |
|---|---|---|---|
| (1) 단일 이벤트 | 69.0% | 0.693 | 72.7% / 85.0% |
| (2) **윈도 집계(12) + 환경 피처** | **87.3%** | **0.878** | **98.9% / 100.0%** |
| (3) 윈도 집계, 환경 피처 제외 | 84.8% | 0.854 | 98.9% / 99.9% |

- 위험 117건 미탐(1.1%) 중 안전 오인은 15건(0.14%) — 잔여 혼동은 대부분
  안전↔주의 경계로 운영상 허용 가능한 방향
- (2)−(3) = +2.5%p: 강우·크레인·노이즈 플로어 공변량이 실제 판별에 기여
  → 기상/작업 정보 연동 설계의 근거
- 교란 없는 원본 30k의 93.1% 대비 87.3% — 환경 주입으로 난이도가 현실
  방향으로 이동했음을 확인

## 5. 원본(30k) 대비 무엇이 개선되었나

| 항목 | 원본 30k | 본 데이터셋 |
|---|---|---|
| 계측 도메인 | 수중 하이드로폰 (dB re 1 μPa) | 볼라드 접촉식 AE (dB_AE) |
| 배경 소음/교란 | 없음 | 크레인·강우·바람 51% 주입 |
| 검출 손실 | 없음 (전수 관측) | 부동 임계 미탐 41.8% |
| 라벨 누수 위험 | 하중 컬럼 동봉 (99.8% 결정) | Truth 접두사로 격리 |
| 로프 규격 | 실험용 24 mm 단일 | 항만용 64–88 mm 메타데이터 |
| 환경 공변량 | 없음 | 강우·바람·크레인·플로어·온습도 |

## 6. 한계 및 재보정 계획

1. **가정 파라미터**: dB_AE 사상값, 감쇠 계수(1.0–2.8 dB/m), 커플링 손실은
   문헌 밴드 기반 가정 — 정량 실측치가 없다. 실센서 설치 후 첫 수집물로
   `PARAMS`(생성기 상단 한 곳에 집약)를 재추정한다.
2. **외삽 구조**: 55세션은 실측 로프 3개(R1–R3)에서 유래. "AE 서명은 %MBL
   기준 불변" 가정으로 64–88 mm 규격에 확장 — 실검증 필요.
3. **성능 수치의 의미**: §4의 87.3%는 생성 규칙 하에서의 학습 가능성 증명이지
   실환경 정확도 예측치가 아니다. 대외 발표 시 "실측 논문 물리 + 배포 환경
   계측 모델 기반 합성 데이터로 파이프라인을 검증"으로 표현할 것.
4. **미반영 요소**: 조석/파랑에 의한 주기 하중 변동, 복수 홋줄 간 간섭,
   센서 노화·탈락, 계절 온도에 따른 로프 물성 변화.
