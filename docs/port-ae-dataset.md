# 항만 볼라드 AE 데이터셋 (port_bollard_ae_dataset.csv)

> 생성일: 2026-07-09 · 생성기: `ml/training-pipeline/port_domain_synthesis.py`
> 원본: `synthetic_rope_damage_classification_30k.csv` (Bashir et al. 2017 실측 기반 합성)

## 무엇인가

수중 실험실 데이터(하이드로폰, dB re 1 μPa)를 **우리 배포 시나리오 — 안벽 볼라드
부착 접촉식 AE 센서(공기/구조 전파) + 실항만 배경 소음** — 도메인으로 변환한
학습용 데이터셋. 원본의 하중-손상 물리(50%/70% MBL 단계, 4개 신호군, 히트카운트)는
보존하고, 배포 환경의 계측 현실(단위 변환·감쇠·검출 임계·기상/작업 교란)을 주입했다.

## 변환 체인 (가정 [A1]~[A7]는 생성기 docstring 참조)

1. **진폭 사상**: dB re 1 μPa → dB_AE(re 1 μV). High 85±6 / Medium 62±5 /
   Low 54±4 / LHF 46±4, 군내 상대 편차(z-score)는 원본 보존
2. **전파 손실**: 취약점 거리(접촉부 편향 지수분포, 평균 ~1.4 m) × 주파수 의존
   감쇠(1.0~2.8 dB/m) + 커플링 손실 4±1.5 dB
3. **검출 임계**: 부동 임계 = 노이즈 플로어 + 6 dB. 플로어 = 34 dB_AE 기저
   + 크레인 +10 + 강우 +0.5/(mm/h) + 강풍 + 정박선 보조기기 +4
   → **로프 이벤트 41.8% 미탐** (기상·거리 의존 — 의도된 현실성)
4. **교란 주입**: 강우(다타격·저진폭), 크레인 충격(중대역·장지속), 바람 마찰
   — 전체 행의 ~51%가 환경 이벤트 (안전 상태의 관측은 대부분 환경음 = 실제와 부합)
5. **메타데이터**: 실계류삭 규격(64~88 mm, MBL≈0.25·d² kN), 기상 공변량
   (Rain_mmh·Wind_mps·Crane_Active·Ambient_Noise_dB·온습도)

## 컬럼 규약

- **학습 피처 후보**: AE 계측(진폭·대역·지속·히트·SNR) + 환경 공변량 + 로프 규격
- **`Truth_*` 컬럼은 학습 금지**(생성 진실값 — Source/Distance/Load ratio, 분석 전용)
- 라벨: `DamageType` (안전/주의/위험) → 백엔드 `NORMAL/CAUTION/DANGER`

## 검증 결과 (XGBoost, GroupKFold 5 by Session)

| 설정 | 정확도 | macro-F1 | 위험 재현율 / 정밀도 |
|---|---|---|---|
| 단일 이벤트 | 69.0% | 0.693 | 72.7% / 85.0% |
| **윈도 집계(12) + 환경 피처** | **87.3%** | **0.878** | **98.9% / 100.0%** |
| 윈도 집계, 환경 피처 제외 | 84.8% | 0.854 | 98.9% / 99.9% |

- 원본(교란 없는) 데이터셋 대비 87% < 93% — 난이도가 현실 쪽으로 이동
- 위험 미탐 117건(1.1%) 중 안전 오인은 15건(0.14%), 나머지 혼동은 안전↔주의 경계(운영상 허용 방향)
- 환경 공변량 +2.5%p (주의 정밀도 개선) → 기상·작업 정보 연동의 가치 실증

## 한계 (발표 시 명시)

- dB_AE 사상·감쇠 계수는 문헌 밴드 기반 **가정**(정량 실측치 부재) — 실센서
  수집 후 재보정 전제
- 55개 세션은 실측 로프 3개(R1~R3)에서 외삽
- 규격(64~88 mm) 확장은 "AE 서명은 %MBL 기준 불변" 가정에 의존
