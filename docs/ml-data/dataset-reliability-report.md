## 한계와 재보정 항목

1. 연결 고리 센서 전달 손실 1.5±0.5 dB는 가정이다.
2. 55세션은 실측 로프 3개에서 파생된 합성 세션이다.
3. 현재 피에조 하드웨어가 실제로 보내는 사실값은 `freqHz`이며, AE 특징은 Backend
   어댑터가 만드는 proxy다.
4. 계류삭 재질·길이·선형밀도별 자연진동수 기준선이 아직 개별 교정되지 않았다.
5. 조석·파랑, 센서 클램프 미끄러짐·노화, 복수 계류삭 기계 결합은 실측 검증이 필요하다.

현장 데이터가 확보되면 계류삭별 slack/critical Hz, 센서 결합 손실, 거리 감쇠를 먼저
재추정하고 동일한 세션 단위 분할로 재평가한다.
