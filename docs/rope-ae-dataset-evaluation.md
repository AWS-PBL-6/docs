> 작성일: 2026-07-09 · 평가 대상: `synthetic_rope_damage_classification_30k.csv`
> 근거 논문: Bashir, Walsh, Thies, Weller, Blondel & Johanning (2017),
> *Underwater Acoustic Emission Monitoring — Experimental investigations and

> Acoustics** 121, 95–103. DOI: 10.1016/j.apacoust.2017.01.033
> 관련 문서: [현재 데이터셋 신뢰성 검증 보고서](dataset-reliability-report.md) ·

## 1. 배경 — 왜 이 논문을 기반으로 했는가

기존에 사용하던 AE-Damage-Detection 계열 데이터셋은 복합재(섬유/수지) 손상
분류용으로, **홋줄(계류삭) 도메인과의 정합성이 낮고 정확도·신뢰성이 부족**했다.
대체 근거를 조사한 결과 위 논문이 채택 기준을 유일하게 충족했다:

1. **동일 대상**: 항만 계류에 실제 쓰이는 합성섬유(폴리에스터) 계류삭의
   인장-파단 실험 — 우리 시스템의 감시 대상과 재질·구조·파괴기구가 일치
2. **실측·동료심사**: Exeter 대학 DMaC 대형 시험기에서 3개 시편(R1–R3)을
   파단까지 실측, Applied Acoustics 게재(peer-reviewed)
3. **정량 수치 공개**: 신호 4개군의 진폭·주파수 대역(Table IV), 하중 단계별
   AE 거동(Section 3.4), 히트카운트(~30회), 시편별 파단 하중(Table V)까지
   데이터셋 생성 규칙으로 옮길 수 있는 수준의 구체성

## 3. 평가 방법론

데이터셋을 그대로 신뢰하지 않고 4단계로 검증했다 (실행 환경:
vendored pandas/sklearn/xgboost, GroupKFold 5-fold).

1. **구조 검증** — 스키마·결측·중복·시계열 정렬
2. **논문 정합성 검증** — 생성값 분포를 Table IV/V 수치와 대조
3. **정보 구조 분석** — 라벨 규칙 결정성(누수), AE 피처만의 판별 상한 추정
4. **모델 실험** — XGBoost 3종 비교로 "어떤 조건에서 신뢰할 수 있는지" 실증

## 4. 평가 결과

### 4.1 구조·논문 정합성: 합격

- 30,000행 / 55 trial, 결측 0, 중복 1행, trial 내 시간 단조증가 100%
- 진폭 평균 90.0/100.0/110.1/125.0 dB — Table IV와 일치, 산포 적정
- Hit_Count 평균 29.4(최대 51) — 논문 서술과 일치
- 최대 하중비 0.864 — R3 실측(87%)과 일치
- ⚠️ 편차 2건: Low-to-high frequency 신호가 논문(시편당 1–2회)보다 과다
  (trial당 평균 ~19회) · 55개 trial은 실측 3개 시편으로부터의 외삽

### 4.2 치명적 주의점: 라벨 누수 구조

`DamageType`은 `Load_MBL_Ratio` 임계(0.5/0.7)의 **결정적 함수**다(일치율
99.8%, 잔여는 경계 반올림). 하중 컬럼을 피처로 쓰면 라벨을 만든 변수로
라벨을 맞추는 순환이 되고, 무엇보다 **배포 환경에서는 홋줄의 실하중을 알 수
없다**(그래서 AE 센서를 다는 것). → `Applied_Load_kN`, `Load_MBL_Ratio`,
절대 `Time_Minutes`는 학습 피처 금지.

### 4.3 XGBoost 실험 (GroupKFold by Trial)

| 실험 | 정확도 | macro-F1 | 위험 재현율 | 해석 |
|---|---|---|---|---|
| (A) 하중 포함 | 99.9% | 0.998 | 99.9% | 라벨 누수 실증 — 무의미한 수치 |
| (B) AE 단일 이벤트 | 66.6% | 0.516 | 78.9% | 단일 이벤트 판별 상한 ~67% (Low amplitude가 3개 클래스 모두에 등장, 안전 재현율 1.1%) |
| (C) 직전 12개 이벤트 윈도 집계 | **93.1%** | **0.919** | **99.5%** (정밀도 99.96%) | 판별력의 실체는 신호군 조성·발생률 — 논문 Fig.10(파단 전 누적 신호 급증)과 부합 |

### 4.4 이용 판단

**조건부 채택.** 아래 조건을 지키면 학습·파이프라인 검증용으로 유효하다:

1. 하중·절대시간 컬럼 제외, `Detected_Location`(시험기 좌표) 제외
2. **시계열 윈도 집계 전처리**(유형별 카운트·이벤트율·진폭/히트 통계) 필수
3. 데이터 분할은 **GroupKFold(Trial 단위)** — 행 단위 랜덤 분할 금지
4. 평가지표는 정확도가 아닌 **위험 클래스 재현율 + 혼동행렬**
5. 라벨 매핑: 안전/주의/위험 → `NORMAL/CAUTION/DANGER`, 보정 확률 → `riskScore`

## 5. 한계 (이 데이터셋 자체의 태생적 제약)

- 성능 수치는 본질적으로 "생성 규칙의 역학습"이므로 실세계 성능을 보증하지 않음
- 수중 하이드로폰 계측(dB re 1 μPa) — 볼라드 부착 공기/구조 전파 센서와
  단위·전파 특성이 다름 → [항만 도메인 변환 데이터셋](port-ae-dataset.md)으로 해소
- 24 mm 실험용 로프 vs 실항만 계류삭(64 mm+) — 절대 임계 이식 불가, %MBL
  비율 개념만 유효
- 실항만 배경 소음(크레인·정박선·강우·바람) 부재 → 동일하게 변환 데이터셋에서 해소
